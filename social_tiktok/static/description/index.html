Installation

Get up and running in minutes
1

Add to addons path

Copy the social_tiktok folder into your custom addons directory and ensure it is listed in addons_path in your Odoo configuration file.

2

Restart the server

Restart your Odoo server so the new module is discovered and its assets are loaded.
3

Install from Apps

Go to Apps, search for Social TikTok, and click Install.
 

Configuration

Three quick steps to connect your TikTok account
1

Register a TikTok App

Log in to developers.tiktok.com, create a new app, and enable Login Kit and Content Posting API. Under App Settings → Redirect URI add https://<your-odoo-domain>/social_tiktok/callback. Note your Client Key and Client Secret.

2

Enter credentials in Odoo

Navigate to Settings → Social Marketing, scroll to Developer Accounts, enter your TikTok Client Key and Client Secret, then save.

3

Authorise your TikTok account

Open Social Marketing → Accounts, click the TikTok media card → Add Account, and authorise the app on TikTok. You will be redirected back to Odoo automatically.

 

Known Limitations

Platform API restrictions to be aware of
🎥
 Video-only posts

TikTok's Content Posting API does not support text-only or image posts.
💬
 No in-app comment management

Comment read/write requires the TikTok Research API, which has a separate approval process.
📈
 No engagement trends

Trend calculation requires historical data not available in the standard API tier.
⏱️
 Access token expiry

Tokens expire after 24 hours; refresh tokens last 1 year. Re-authorise when prompted.
